# Компостер (kompostr)

Цифровой компостер: оплата проезда в общественном транспорте по QR-коду.

Пассажир пополняет баланс в личном кабинете, в автобусе сканирует QR-код на наклейке и оплачивает поездку. Купленный билет можно показать контролёру.

Пет-проект для портфолио: frontend + backend на TypeScript.

## MVP

- **Приложение пассажира**: регистрация, баланс и пополнение, оплата проезда по QR, активный билет, история поездок.
- **Админка перевозчика**: маршруты и автобусы, генерация QR-кодов для наклеек (маршрут + автобус).
